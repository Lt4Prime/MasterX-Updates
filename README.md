# MasterX

## Intelligent System Control Platform

MasterX es una plataforma de control inteligente para Windows enfocada en la integración de herramientas de automatización, inteligencia artificial y gestión avanzada del sistema mediante una interfaz moderna.

---

## Características principales

### 🖥️ Interfaz de control avanzada

MasterX cuenta con una interfaz HUD personalizada diseñada para centralizar funciones del sistema en un entorno rápido, organizado y visualmente moderno.

Incluye:

- Panel principal de control.
- Modo compacto.
- Personalización de visualización.
- Estado del sistema en tiempo real.

---

## 🤖 Integración con Inteligencia Artificial

MasterX incorpora un núcleo preparado para trabajar con diferentes servicios de inteligencia artificial.

Funciones actuales:

- Integración con Gemini Core.
- Modos de respuesta rápido y preciso.
- Arquitectura preparada para nuevos modelos de IA.

---

## 🔄 Sistema de actualización automática

MasterX cuenta con un sistema propio de actualización mediante servidores GitHub.

Características:

- Detección de nuevas versiones.
- Comparación entre versión local y remota.
- Descarga automática de actualizaciones.
- Validación mediante SHA256.
- Verificación de integridad antes de instalar.

---

## 🔐 Sistema de licencia

Sistema preparado para gestionar versiones y distribución del software.

Incluye:

- Activación de licencia.
- Estado de licencia visible.
- Base para futuras versiones comerciales.

---

## 📂 Gestión de información local

MasterX utiliza almacenamiento local para mantener:

- Configuración del usuario.
- Historial de ejecución.
- Datos internos del sistema.

---

## ⚙️ Tecnología

Desarrollado utilizando:

- Python
- PyInstaller
- JSON
- GitHub Releases
- SHA256 Verification
